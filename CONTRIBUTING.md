# Contributing

Corrections, replacements for dead links, and suggestions for genuinely useful resources are welcome.

## Pull requests

- Open one pull request per addition or fix, with a short note on why the resource belongs here.
- Search the list first so you do not add a duplicate.
- The resource must be real, currently available, and useful to people learning Mandarin. Do not add abandoned sites, parked domains, or unmaintained repositories.
- Prefer primary official URLs that return a normal page.

## Entry format

Use a single line:

```markdown
- [Name](https://example.com) - Short objective description. (free)
```

Rules:

- The description starts with a capital letter and ends with a period.
- Keep the description to one sentence. State what the resource does, not that it is the best, easiest, or only option.
- Add a price tag when it is clear: `(free)`, `(freemium)`, or `(paid)`.
- Do not use official exam wording for third-party practice tests or word lists.
- Do not add emoji, badges, or promotional blurbs.

Place the entry in the most natural existing section. Suggest a new section only when a resource does not fit any of the current ones.

## Conflicts of interest

You may propose your own project if it clearly belongs on a list of this kind. Describe it in the same neutral style as every other entry, and mention the connection in the pull request.

## Conduct

Be respectful in issues and pull requests. The goal is a list people can trust, not a debate about which app to buy.
